Jobify - MERN Stack Job Application Tracker
🌟 Introduction
Jobify is a full-stack job application tracking system built using the MERN stack. It allows users to manage, filter, and track their job applications, updating statuses like pending, interview, and declined. The application includes user authentication, role-based authorization (admin/user), and dedicated dashboard statistics.

✨ Features
Authentication: Secure user registration and login using JWT.

Authorization: Role-based access control (Admin/User). Includes a Demo User mode with read-only restrictions.

CRUD Operations: Create, Read, Update, and Delete job applications.

Search & Filter: Dynamic search functionality to filter jobs by status, type, location, and sorting.

Statistics: Visual charts and statistics to track application trends over time.

User Profile: Ability to update user information and profile picture (integrated with Cloudinary).
